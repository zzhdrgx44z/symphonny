✧ Sumber Result Otomatis

Sumber dipilih: DOCS SEPUTAR LINE TOGEL — tab POST RESULT WLA. Hanya hasil berstatus DONE yang dibaca. Karena dokumen tidak dipublikasikan, jalankan penghubung Google Apps Script (file Code.gs disediakan), deploy sebagai Web App, lalu tempel URL /exec di bawah. URL Apps Script memakai JSONP agar bisa bekerja juga ketika HTML dibuka sebagai file.

Jika gagal, buka URL Apps Script langsung. Untuk respons otomatis dari HTML, Web App wajib mendukung ?callback= (JSONP). Gunakan kode Code.gs V14 dan lakukan redeploy New version.
✅ Deployment Apps Script terbaru telah dipasang sebagai default dan pemeriksaan otomatis diaktifkan setiap 30 detik. Klik Cek Sekarang untuk memeriksa koneksi. Jika gagal, periksa apakah deployment sudah memakai Code.gs V14 dan izin Web app sudah sesuai; untuk memperbarui gunakan Deploy > Manage deployments > Edit > New version, dan pastikan menggunakan Code.gs V14 (JSONP). Keamanan: siapa pun yang mengetahui URL /exec dapat membaca data hasil yang disediakan endpoint. Data tab lain tidak perlu dibagikan.

⌘ Cara Mengaktifkan

1. Buka HTML di Chrome atau Edge, lalu klik Aktifkan / Tes Alarm.
2. Izinkan notifikasi desktop melalui tombol di bagian atas bila dibutuhkan.
3. Biarkan tab tetap terbuka untuk alarm jadwal.
4. Untuk alarm angka result, masukkan nomor asli atau sambungkan sumber JSON.
